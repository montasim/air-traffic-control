# Store hero image

The current Windows and Xbox hero is `super-hero-gameplay-1920x1080.png`, derived from the actual River Bend gameplay screenshot `05-river-bend-gameplay.png`.

The full screenshot is proportionally scaled to 1728 × 1080 and centered on a 1920 × 1080 canvas with 96-pixel forest-green side margins. No game UI, artwork, or gameplay content was added or removed.

This replaces the generated promotional illustration, which did not accurately represent the game's visual style.
